# Employee Engagement, Burnout & Attrition Analysis

## Project Overview

This project analyzes employee engagement, burnout risk, workload patterns, and attrition behavior using HR analytics data.

The project combines feature engineering, exploratory data analysis (EDA), and interactive dashboarding to identify workforce patterns associated with employee retention and employee experience.

---

## Objectives

- Construct an engagement index using satisfaction-related metrics
- Identify burnout risk indicators
- Analyze workload and stress patterns
- Study engagement across career stages
- Compare engagement and burnout against attrition
- Build an interactive Streamlit dashboard

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- Jupyter Notebook

---

## Feature Engineering

### Engagement Index
The engagement index was constructed using:
- Job Involvement
- Job Satisfaction
- Environment Satisfaction
- Relationship Satisfaction

### Burnout Risk
Burnout risk was approximated using:
- Overtime frequency
- Work-life balance indicators

---

## Exploratory Data Analysis

The analysis explored:
- Engagement distribution
- Burnout risk levels
- Overtime vs attrition
- Business travel vs burnout
- Career-stage engagement patterns
- Engagement vs attrition relationships

---

## Key Insights

- Employees working overtime showed significantly higher attrition rates
- Employees who left the company had lower engagement scores on average
- Frequent business travel showed slightly elevated burnout indicators
- Engagement differences across tenure groups were relatively modest

---

## Dashboard

The project includes an interactive Streamlit dashboard for exploring:
- Employee engagement metrics
- Burnout risk patterns
- Attrition trends
- Career-stage analysis

---

## Limitations

- Burnout risk is an engineered metric rather than a directly observed variable
- The analysis identifies associations rather than causal relationships
- Engagement index uses equal weighting across satisfaction metrics
